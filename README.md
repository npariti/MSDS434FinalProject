# Austin Crime Prediction Web App (Demo Mode)

This is a Flask-based web application that simulates displaying crime category
predictions generated by a Logistic Regression model in BigQuery ML.

## Overview
Originally, the application queried a BigQuery ML model to generate predictions.The original model, model2, was a BigQuery ML Logistic Regression model stored in a GCP dataset. Since the model and dataset are no longer available, this repository includes
mocked prediction data to allow the web interface to run locally.

## Technologies Used
- Python
- Flask
- Pandas
- HTML

## How It Works
1. The Flask app serves a web page with a table of sample predictions.
2. Each prediction includes incident number, crime type, predicted type, and confidence.
